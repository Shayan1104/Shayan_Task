# 🏘️ Zameen.com Residential Plot Price Predictor

A machine learning project that predicts residential plot prices in Pakistan
using data from Zameen.com property listings.

## 🚀 How to Run

### Step 1: Install Dependencies
```bash
pip install -r requirements.txt
```

### Step 2: Run the Pipeline (Stages 1-4)
Run each stage in order. Each stage depends on the previous one:

```bash
python stage1_understand_data.py    # Explore raw data
python stage2_clean_data.py         # Clean and save clean_data.csv
python stage3_eda_charts.py         # Generate EDA charts
python stage4_train_models.py       # Train models and save .pkl files
```

### Step 3: Launch the Web App
```bash
streamlit run app.py
```
The app will open in your browser at `http://localhost:8501`.
- **🎨 Theme Support**: Features both **☀️ Professional Light** (clean enterprise look) and **🌙 Executive Dark** themes via the sidebar radio toggle.
- **🔮 Interactive Valuation**: Enter any locality and plot size to obtain real-time consensus valuations across all 6 models.

## 🤖 Models Trained

| Algorithm | Type | Purpose |
|-----------|------|---------|
| Linear Regression | Regression | Baseline linear model |
| Polynomial Regression (d=2) | Regression | Captures non-linear curves |
| K-Nearest Neighbors | Regression | Distance-based, tuned with GridSearchCV |
| Support Vector Regression | Regression | Kernel-based, tuned with GridSearchCV |
| Decision Tree | Regression | Rule-based, tuned with GridSearchCV |
| Logistic Regression | Classification | Classifies into Low/Medium/High price bins |

## 📊 Features Used

- **area_marla**: Plot area in Marla (1 Kanal = 20 Marla)
- **log_area**: log₁₀ of area (captures power-law relationship)
- **locality**: Neighborhood name (one-hot encoded)

## 📝 Notes

- Only **Residential Plots** listed **For Sale** are used
- Prices are in Pakistani Rupees (PKR)
- Misaligned rows (with shifted columns) are dropped
- Outliers detected using IQR on log₁₀(price per Marla)
- Localities with fewer than 10 listings are grouped as "Other"
